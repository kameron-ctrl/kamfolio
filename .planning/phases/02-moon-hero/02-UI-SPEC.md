## Entrance Animation Contract

| Property | Value | Source |
|----------|-------|--------|
| Start Z | `-15` (distant, renders as tiny point) | D-11 |
| End Z | `0` | D-11 |
| Duration | `2.5s` | D-11 / HERO-04 |
| Ease curve | `power3.out` | D-13 / RESEARCH.md Pattern 6 |
| Trigger condition | `texturesLoaded` flag set true after `useTexture` `onLoad` fires | D-12 / D-09 |
| Canvas reveal | CSS `opacity: 0 → 1` over `0.5s ease` on wrapper div | D-02 |
| Timing | Canvas fade-in and Z fly-in start simultaneously once textures resolve | D-12 |
| Implementation | `gsap.to(meshRef.current.position, { z: 0, duration: 2.5, ease: 'power3.out' })` inside `useGSAP` | RESEARCH.md Pattern 6 |

The entrance is a Z fly-in using real 3D perspective foreshortening — NOT a CSS scale transform. The perspective shift as the moon approaches the camera is the intended visual quality. Do not substitute a scale lerp.

**Source:** CONTEXT.md `<specifics>` block — entrance is Z fly-in, not scale lerp.

## Reduced Motion Contract

Per REQUIREMENTS.md QUAL-03, `prefers-reduced-motion: reduce` must disable all animations and show a static fallback.

| Animation | Normal Behavior | Reduced Motion Behavior |
|-----------|----------------|------------------------|
| Moon Z fly-in | Lerp from `z = -15` to `z = 0` over 2.5s | Skipped — moon renders at final `z = 0` immediately |
| Canvas opacity fade | 0.5s CSS transition | Retained — opacity change is not motion |
| Moon self-rotation | `0.0005` rad/frame in `useFrame` | `0` — rotation increment set to zero |

Implementation gate in `MoonScene.tsx`:

```tsx
const prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches

useGSAP(() => {
  if (!meshRef.current || !texturesLoaded) return
  if (prefersReducedMotion) {
    meshRef.current.position.z = 0  // instant, no tween
    return
  }
  gsap.to(meshRef.current.position, { z: 0, duration: 2.5, ease: 'power3.out' })
}, { dependencies: [texturesLoaded] })

useFrame(() => {
  if (meshRef.current && !prefersReducedMotion) {
    meshRef.current.rotation.y += 0.0005
  }
})
```

**Source:** REQUIREMENTS.md QUAL-03. Phase 4 owns the full static fallback — Phase 2 owns the 3D animation subset.

## Copywriting Contract

Phase 2 has no visible copywriting in production. The moon is purely visual.

| Element | Copy |
|---------|------|
| Primary CTA | None in Phase 2 |
| Empty state | Not applicable — no data-driven content |
